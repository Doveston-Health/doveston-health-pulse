PUL-011 XERO READ-ONLY FINANCE
==============================

Copy every ZIP file to its matching project path. The ZIP contains configuration documentation, one Prisma migration, Xero integration and finance modules, frontend files and tests.

Windows setup:
1. Run npm.cmd install.
2. Run npm.cmd run db:generate and npm.cmd run db:migrate:deploy.
3. Create a Xero Web App and register exactly http://localhost:3000/api/integrations/xero/callback.
4. Copy the XERO_* placeholders from .env.example into private .env values.
5. Generate a private key with: node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
6. Run npm.cmd run dev, sign in as DIRECTOR or PRACTICE_MANAGER, connect Xero, select the correct organisation and run Sync Xero.
7. Verify Finance shows "Read-only insights from Xero" and the correct freshness timestamp.

Do not change PowerShell execution policy. Do not paste client secrets, tokens or encryption keys into chat, logs or screenshots. Xero remains the accounting source of truth and all accounting actions must be completed there.

Verification:
npm.cmd run lint
npm.cmd test
npm.cmd run quality
npm.cmd run db:generate
npm.cmd run db:migrate:check
git diff --check

The migration creates tenant-scoped, Decimal-safe Xero connection, token, organisation, contact, invoice, payment, report-snapshot and sync-run tables. It does not store bank numbers, addresses, phone data, invoice line descriptions, attachments or raw Xero payloads.
