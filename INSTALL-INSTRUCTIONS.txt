PUL-007 DOCUMENTATION PACKAGE
=============================

Purpose
-------
This ZIP contains the complete PUL-007 documentation-only change set.
It does not contain application code, dependencies, database migrations,
authentication changes, routes, or runtime configuration.

Installation
------------
1. Close any editor that may be changing README.md.
2. Make a backup of your repository, or confirm your work is committed.
3. Extract this ZIP.
4. Copy README.md to the root of the doveston-health-pulse repository,
   replacing the existing README.md.
5. Copy docs\MASTER-PROJECT-BRIEF.md to the repository's docs folder.
   Create the docs folder if it does not already exist.
6. Review the two files with:

   git diff -- README.md docs/MASTER-PROJECT-BRIEF.md

7. Confirm no other project files changed with:

   git status --short

Verification
------------
Because PUL-007 changes documentation only, no npm installation, database
migration, application startup, authentication, route, dependency or
runtime behaviour change is required by this package.

On Windows, any optional documentation verification command that invokes
npm or npx must use npm.cmd or npx.cmd. Do not change PowerShell execution
policy. The standard local-development command is npm.cmd run dev.
