PUL-006 — AUTHENTICATION AND ROLE-BASED ACCESS CONTROL
======================================================

IMPORTANT
---------
Back up your project before installing these files.
This package must be installed into the Doveston Health Pulse project on branch:

feature/pul-006-authentication-rbac

The ZIP contains only files added or changed for PUL-006. It is not a complete
copy of the project.


HOW TO INSTALL
--------------
1. Close the running Pulse application.
2. Open the root folder of the doveston-health-pulse project. This is the folder
   that already contains package.json, README.md, public, prisma, and src.
3. Extract the contents of this ZIP directly into that project root.
4. Allow Windows or your archive program to merge folders and replace existing
   files when prompted.
5. Open a terminal in the project root and run:

   npm install
   npx prisma generate
   npm run db:migrate:deploy
   npm run db:seed
   npm test

6. Copy the new settings from .env.example into your local .env as appropriate.
   Do not commit real passwords or secrets.
7. Create the initial Director account by setting:

   BOOTSTRAP_ADMIN_EMAIL
   BOOTSTRAP_ADMIN_NAME
   BOOTSTRAP_ADMIN_PASSWORD

   Then run:

   npm run user:bootstrap

8. Start Pulse and open /login:

   npm start
