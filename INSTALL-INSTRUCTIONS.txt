WINDOWS SETUP AND VERIFICATION
------------------------------

From PowerShell in the repository root:

1. Copy .env.example to .env if a local .env does not already exist.
2. Keep the existing DATABASE_URL and SESSION_SECRET values private.
3. Start PostgreSQL if it is not already running.
4. Run:

   npm.cmd install
   npm.cmd run db:generate
   npm.cmd run db:migrate:check
   npm.cmd run lint
   npm.cmd test
   npm.cmd run quality
   npm.cmd run dev

Do not change PowerShell execution policy. Use npm.cmd and npx.cmd on Windows.

Open the application, sign in with an approved local account, and select
Operations. Confirm the source label says "Read-only insights from Cliniko",
the current measures load, period controls work, and patient search rejects a
one-character query. Use Cliniko for every operational change.

SECURITY AND PRODUCT BOUNDARY
-----------------------------

Clinic Operations queries PostgreSQL only. It does not call Cliniko while a
page is loading, write to Cliniko, expose notes or raw source payloads, infer
attendance or discharge, or calculate unsupported capacity/utilisation.
Patient search terms are excluded from structured request logs.
